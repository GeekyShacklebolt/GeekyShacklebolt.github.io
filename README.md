# shivasaxena.com

Personal site of Shiva Saxena. One page, hand-written HTML, CSS and a little JavaScript.
No build step. Served by GitHub Pages from `master`.

```
index.html      the page
styles.css      all styling, light and dark
script.js       section reveal, active nav, portrait parallax
assets/         the one photo
CNAME           www.shivasaxena.com
```

Run locally with any static server, for example `python3 -m http.server 8000`.
